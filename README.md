- 💼 Atuo com suporte de T.I para o **Instituto Multiprofissional de Ensino (IME)**, **SOBREC** e **Editora Integrar**, com foco em gestão de sistemas **OJS** e manutenção de plataformas.

- 🎓 Organizo congressos e seminários acadêmicos.
- 📚 Atualmente aprendendo mais sobre **Go**, **Cloud** e **arquitetura de sistemas**.
